#  MyFinancePlanner

Выпускная квалификационная работа (диплом), 4 курс.
Мобильное приложение для планирования личных финансов: учёт транзакций,
постановка финансовых целей и контроль их достижения.

## О проекте

**MyFinancePlanner** — мобильное приложение на Unity (C#) для планирования
личного бюджета. Пользователь фиксирует доходы и расходы, ставит финансовые
цели и отслеживает прогресс их достижения. Данные хранятся локально в
базе данных, что обеспечивает автономность и конфиденциальность.


## Стек технологий

- **Движок:** Unity
- **Язык:** C#
- **Платформа:** Android / iOS
- **База данных:** SQLite
- **UI:** Unity UI (uGUI) / TextMeshPro
